# Practical 16: Product Management (Create Operation)

**Aim**: Develop a Product Management React application that allows the user to enter product details through a form and add a new product to the application.

## Key Features
- **Create Operation**: Controlled form with inputs for Name, Category, Price, Stock, and Description.
- **State Updates**: Appends newly created product with unique ID and timestamp to the product state list.
- **Inventory Metrics**: Dynamically displays item count and total inventory value.

## How to Run
```bash
npm install
npm run dev
```
